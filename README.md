# KARIA Inventory Management System

A native Android application designed to streamline stock control, product catalog management, and inventory reporting for small to medium enterprises. Built with modern Android development standards utilizing **Kotlin**, **Jetpack Compose**, and **Firebase Firestore**.

## Features
* **Real-time Stock Tracking:** Syncs inventory updates dynamically across devices using Firebase Firestore.
* **Product Catalog:** Create, edit, and organize product categories with pricing and quantity metrics.
* **Modern UI:** Built fully with Jetpack Compose for smooth, responsive user interfaces.
* **User Authentication:** Secure access workflows for inventory managers and administrators.

##  Tech Stack & Architecture
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Backend / Database:** Firebase Firestore / Firebase Auth
* **Architecture:** MVVM (Model-View-ViewModel)
